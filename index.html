FIRST PRINCIPLES

Two different jobs.

Antivirus examines files and device activity to identify possible malware. A firewall examines network traffic and decides which connections to allow or block.

Neither guarantees safety. A firewall can allow a connection containing harmful content; antivirus may not recognise a new threat.

Prediction. A malicious file arrives over an allowed web connection. Which tool might still detect it? Antivirus, because it examines files and device behaviour.

EXPERIMENT A

What counts as suspicious?

A signature is a recognisable pattern from known malware. Exact matches can miss modified threats. Heuristics look for suspicious behaviour, but may also flag legitimate software.

Experiment: Run a signature-only scan. Then enable behavioural checks. Try changing the threshold and compare the mistakes.

EXPERIMENT B

Who gets through?

An IP address identifies a device on a network. A port helps identify a service. For example, HTTPS commonly uses TCP port 443; DNS often uses UDP port 53. A protocol, such as TCP or UDP, specifies how communication operates.

A firewall uses rules to permit or deny connections. In this simplified model, rules are checked from top to bottom; the first match wins. Traffic matching no rule is blocked.
